# 배포 구성 (시험장 실행 기준)

시험장에서 실제로 도는 구성이다. 2026-09-16 기준. 다른 곳과 어긋나면 **이 문서와 `results/BASELINE.json` 이 맞다.**

실행 파일은 `_kisa_port/tools/kisa_items.py` **하나뿐이다.** 항목마다 다른 파일을 쓰지 않는다.

```
python _kisa_port/tools/kisa_items.py --item <fire|intrusion|loitering|falldown> --rtsp <주소> --out <폴더>
```

---

## 1. 항목별 구성과 실측

| 항목 | 점수 | 가중치 | 입력 | 판정 |
| :-- | --: | :-- | :-- | :-- |
| 방화 | **100.00** | `fire_fog.pt` @640 + `fire_small.pt` @960 (앙상블) | 6분할 타일, **낱장 추론** | 불 ≥0.40 이 20스텝(10초) 창에 3회 · 지연 10초 |
| 쓰러짐 | **100.00** | `yolo11x-pose.pt` @1280 | 0.1초 간격 | SeqNet 문턱 0.755 · 연속 4창 |
| 배회 | **96.55** | `person_v2.pt` | BoT-SORT 전체프레임 @640 | 구역 체류 6초 · 끊김 6 · 확정대기 5초 · **늦은 일행(20초/3명/방금도착)** · 지연 10초 |
| 침입 | **94.74** | `person_v3.pt` | 3x3 타일 @960, **부분검출 억제 끔** | 연속 2표본 · 확정대기 · 끊김 허용 2 |

실측 로그와 정검·미검·오검 수는 `results/BASELINE.json` 에 있다. 점수를 묻는 질문은 그 파일 하나만 본다.

## 2. 쉽게 틀리는 곳

| 항목 | 이렇게 하면 틀린다 | 무슨 일이 나나 |
| :-- | :-- | :-- |
| 방화 | 6뷰를 한 배치로 추론 | 크기가 다른 타일이 공통 크기로 패딩돼 값이 달라진다(0.545 대 0.519). 안개편이 정검 대 오검으로 갈린다 |
| 방화 | 연기 채널을 켠다 | 88.89 -> 63.16. 안개편은 연기가 0초부터 높다. `smoke=1.1` 은 "절대 만족 안 함" 이라는 뜻 |
| 침입 | 타일 NMS 의 부분검출 억제를 켠다 | 94.74 -> 87.72. 제출 경로는 `contain=None`(끔) |
| 침입 | 타일 입력을 1280 으로 올린다 | 94.74 -> 84.21. 학습 해상도(960)와 어긋난다 |
| 배회 | 타일 검출 덤프로 규칙을 고른다 | 제출은 BoT-SORT 전체프레임이다. 덤프가 다르면 68.97 |
| 쓰러짐 | 자세 해상도를 640 으로 내린다 | 먼 사람 관절이 흔들려 트랙이 잘게 끊긴다 |

## 4. 손댄 뒤 반드시 돌리는 것

| 명령 | 무엇을 보나 |
| :-- | :-- |
| `python scripts/check_repro.py` | 덤프 재계산이 `BASELINE.json` 실측과 같은가 |
| `python scripts/fire_weight_check.py <실험> <가중치.pt> [해상도]` | 그 덤프를 만든 가중치가 맞는가 |
| `MROD_PW=... python scripts/check_thor.py` | Thor 배포본 8개가 서버와 같은가 (작업 PC 에서) |
| `python scripts/check_models.py` | 운영 가중치가 전부 `results/MODELS.json` 에 적혀 있는가 |
| `python scripts/check_layout.py` | 산출물이 규약 자리에 있는가 |
| `python scripts/audit_stale.py` | 판정 중복·죽은 경로·낡은 산출물·미참조 스크립트 |

## 5. 알아 둘 것

- `fire_small.pt` 의 원본은 `runs/` 에 없다. 2026-09-15 재학습 실패(`train_failed`, epoch 3)가 그 자리를 덮어썼고,
  쓸 수 있는 것은 `logs/_archive/2026-09-15/r960오염실험/` 사본뿐이다. `fire_weight_check.py` 로 덤프 재현을 확인했다.
  지금 도는 `f960_best_s` / `f1280_best_s` 가 눈편을 잡으면 이 의존이 없어진다.
- 방화 채점셋은 10편이라 한 편이 1.6점이다. LOOCV 80.00(낙관 +20). `C00_089_0001` 과 `C00_195_0001` 은 창 여유가 0.5초다.
  **100 을 실력으로 읽으면 안 된다.** 안전 구간은 90~94.74.
- 배회는 30편 · LOOCV 96.55 · 낙관 0.00 이라 네 항목 중 가장 단단하다.
