> 누가 어떤 개선을 제안했고, 어떻게 확인했고, 지금 어디까지 왔는지 한 곳에 적는다. 새 제안이 나오면 한 줄 더하고, 확인이 진행되면 그 줄의 결과 · 상태를 고친다(지우지 않는다).

> 시작: 2026-09-29. 이전 제안(09-28 이전)은 `EXPERIMENTS.md` 1 · 4절과 연구일지에 있다.

## 상태 뜻

| 상태 | 뜻 |
| :--- | :--- |
| 진행 중 | 학습 · 덤프 · 채점이 도는 중 |
| 재평가 필요 | 지금 규칙을 그대로 둔 채 잰 결과라 결론을 내지 않는다. 규칙을 맞춰 다시 잰다 |
| 채택 후보 | 채점편에서 나아졌으나 채점편 밖 확인 전 |
| 채택 | 제출 도구 · 학습 기본값에 반영 |
| 보류 | 지금은 안 하지만 조건이 되면 다시 본다 |
| 기각 | 규칙을 그 설정에 맞춰 골라도 나빠졌다 |
