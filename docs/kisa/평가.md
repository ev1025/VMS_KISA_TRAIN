## 2. 판정 정의 (F1 방식, 안내서 §3)

| 판정 | 조건 |
|---|---|
| 정상검출(TP) | SA 의 AlarmDescription 이 GT 와 일치 **그리고** SA 의 StartTime 이 항목별 "정상검출 시각" 창 안 |
| 미검출(FN) | GT 에 이벤트가 있는데 SA 에 이벤트 종류·시각을 기록하지 못함 |
| 오검출(FP) | SA 의 이벤트 종류가 GT 와 다름 **또는** StartTime 이 창 이전·이후 |

- 창을 벗어난 경보 = **오검출 + 미검출 동시**(GT 는 못 맞췄고 경보는 냈으므로). 늦은 경보가 무경보보다 나쁘다.
- 정상검출 시각 창 = **[이벤트 시작시각 − 2초, 이벤트 시작시각 + 10초]** (4항목 공통).
- 사람 이외 차량·조류 등은 검출하면 안 된다(사람 항목 오검출).
- 항목 선택 시험이므로 신청 항목 외 이벤트를 SA 에 쓰면 오검출. 우리 SA 생성기는 `--item` 하나만 기록한다.

### 점수 산출식

```
검출률 r = TP / (TP + FN)
정밀도 p = TP / (TP + FP)
점수    = 2 × r × p / (r + p) × 100
```

안내서 예시(TP 90 · FN 10 · FP 30) → r 0.90, p 0.75 → **81.81점**.
한 편이 창 밖 경보가 되면 FN +1, FP +1 두 번 깎인다. 10편 항목에서 1편 미검출 = 94.74, 1편 창 밖 = 90.00, 2편 미검출 = 88.89.

## 3. 항목별 이벤트 시작시각 (안내서 표, 일반분야)

| 항목 | 정의 | 이벤트 시작시각(GT StartTime) | 특이사항 | SA Description |
|---|---|---|---|---|
| 방화 | 사람이 방화하여 연기 또는 화염이 발생 | **최초** 연기 또는 화염 발생 **+10초** | 최초 발생 1건만 SA 기록 | `FireDetection` |
| 침입 | 1명 또는 다수가 특정 영역에 진입 | 사람 **몸 전체**가 영역에 진입한 시각 | 다수면 **마지막 사람** 기준 | `Intrusion` |
| 배회 | 특정 영역에서 10초 이상 배회 | 몸 전체가 영역 진입 후 **10초 경과** 시각 | 다수면 **마지막 사람** 기준 | `Loitering` |
| 쓰러짐 | 사람이 쓰러진 상황 | 바닥에 **머리가 닿는** 시각 | 다수면 **처음** 쓰러지는 사람 기준. 싸움 영상의 쓰러짐은 SA 기록 금지 | `Falldown` |

- Description 은 대소문자·스펠링 엄격(FAQ). `AlarmDuration` 은 채점에 쓰이지 않지만 형식은 맞춘다.
- 침입·배회의 "영역"은 영역파일(`C00_XXX.map`, 장소 코드별)로 주어진다. 쓰러짐·방화는 영역 없음.
- 파일명 규칙 `C00_장소3자리_영상4자리.mp4`. 같은 장소 코드는 같은 카메라·구역이다.

## 4. 시험 절차와 채점 시점

| 단계 | 내용 | 채점 |
|---|---|---|
| 배포용 DB | 신청서 제출 → 저장매체로 수령. 우리가 GT 포함해 보유 | 자체 채점(오프라인 채점기 `score_kisa`) |
| 1·2단계 | 시험신청서·보안서약서 제출, 사전시험 일자 확정(2026-09-28) | 없음 |
| 3단계 사전시험 | 우리 PC 지참 방문. 진흥원 PC 가 시험용 DB 를 RTSP 로 실시간 전송, 우리 PC 가 SA 자동 저장 → 제출 | 진흥원이 GT 와 비교해 **점수 통보** |
| 4단계 본시험 | 신청서·공문 제출 → PC 와 **SA 생성 매뉴얼** 제출. 진흥원 직원이 매뉴얼대로 조작, **인증용 DB**(비공개)로 평가 | 90점 이상이면 5단계 |
| 5단계 인증 | 인증서 발급 | |

- 사전시험은 점수만 받는 리허설이다. 본시험은 제출 후 수정 불가, 종료 후 저장매체 파기.
- 시험용·인증용은 실시간 RTSP 스트림이다. 오프라인 채점과 달리 되감기·재추론 불가, 클립 사이 스트림 단절(세부: 체크리스트 §2·§3.1).
- 배포용·시험용은 서울·부산, 인증용은 서울만.

## 5. 우리 자체 채점 방식과 공식 채점의 관계

| 지표 | 무엇 | 어디서 | 용도 |
|---|---|---|---|
| **채점 F1** | 배포용 DB 편별 SA ↔ GT, 위 §2 규칙 그대로 | `score_kisa`, 라이브 `kisa_items.py` | 공식 점수 예측. 편수가 10~30 이라 값이 계단식(10편: 66.67·82.35·88.89·94.74) |
| **채점셋 mAP** | 배포용 검증영상에서 우리가 손라벨·전파한 박스로 잰 검출 mAP50 (방화 771프레임, 사람 1,289프레임) | `eval_map.py` → `results/<실험>/eval_map.json` | 모델 간 검출력 비교. F1 보다 민감. **공식 채점과는 무관한 내부 지표** |
| 학습 검증 mAP | 학습 목록에서 뽑은 val | ultralytics 학습 로그 | 참고만. 과거 val_small 0.87 은 학습 데이터 누수였음 |

- 배포용 검증영상은 **학습에 넣지 않는다**(`use: eval`, 빌드 시 누수 검사). 배경 하드네거티브로도 쓰지 않는다. 라벨은 mAP 평가에만 쓴다.
- 규칙 파라미터(임계·연속 프레임·hold·gap)는 배포용 10~30편에 스윕한 값이라 과적합 위험이 있다. 스윕 곡선이 평평한 값만 채택한다(침입 gap 1~4 전 구간 동일 → 채택, 트랙 신뢰도 규칙은 단일 첨점 → 기각).

| 항목 | 편수 | 점수 | TP / FN / FP | 미검·오검 편 |
|---|---|---|---|---|
| 침입 | 30 | **94.74** | 27 / 3 / 0 | 미검 C00_249_0003 · C00_255_0001 · C00_275_0001 |
| 배회 | 30 | **93.10** | 27 / 3 / 1 | 미검 C00_115 · C00_225, 오검 C00_211 |
| 쓰러짐 | 10 | 88.89 | 8 / 2 / 0 | 미검 C00_034 · C00_235 |
| 방화 | 10 | 82.35 | 7 / 3 / 0 | 미검 C00_195_0001 · C00_216_0003 · C00_272_0003 |

- 90 미달 = 쓰러짐(1편 부족)·방화(2편 부족). 방화는 10편이라 1편 = 5~6점.
- 본시험 인증용은 편수가 많고(방화 100·침입 300 급) 비공개. 배포용 점수는 상한 추정치로만 본다.

### 죽은 카드 원인 (프레임·박스 크기·모델 신뢰도 확인, 2026-09-12)

| 편 | 조건 | 관찰 | 원인 분류 |
|---|---|---|---|
| 방화 C00_195_0001 | 주간 **안개** | 최고 모델(wildall)이 안개를 연기 0.96 으로 **상시** 판정, 불은 GT 뒤에야 0.68. 손라벨 불 박스 **약 15×13px** | 안개 = 연기 오인 + 초소형 불 |
| 방화 C00_216_0003 | 주간 **눈** | 모든 모델 신뢰도 ~0. 불 박스 **약 18×9px**(정검 편 평균 31×38) | 초소형·원거리 불, 눈 배경 |
| 방화 C00_272_0003 | | 오프라인 최고 모델 + 타일에서는 정검. 라이브 경로가 옛 모델·옛 규칙 사용 | **데이터 문제 아님**, 라이브 모델 갱신 |
| 침입 C00_275_0001 | **야간 눈** | 구역 내 검출 단일 표본 | 야간·눈 사람 검출 |
| 침입 C00_249_0003 | 주간 눈, **원거리** | 단일 표본 | 작은 사람 |
| 침입 C00_255_0001 | **야간 IR**, 매우 어두움 | 구역 내 박스 0 | IR 저조도 사람 검출 |

- 공통점은 **작은 객체 + 악천후(안개·눈)·야간**이다. 연기 데이터 양이 부족한 문제가 아니다(연기가 잘 보이는 편은 이미 정검).
- 필요한 데이터: 안개 속 불 양성 + 안개 배경 하드네거티브(연기 오인 억제), 눈 배경 + 소형 불, 소형 객체 학습(타일·960 이상), 야간·눈·IR 사람 프레임(라이선스 문제로 KISA 연구개발 영상 손라벨·전파로만 확보).
- 연기 데이터는 별도로 유의미하다. 채점셋 연기 mAP50 이 0.15~0.23 으로 불의 절반이라 인증용 100편에서 연기 선행 편을 놓칠 위험을 줄인다.

## 7. 제출물·주의

- 사전시험: PC 지참, 백신 설치, 인터넷 불가, 영역파일·목록파일 로컬 저장, SA 자동 저장 폴더. 절차는 체크리스트 §5.
- 본시험: PC + **SA 생성 매뉴얼**(진흥원 직원이 그대로 조작). 제출 후 수정 불가 → 임계·규칙은 사전시험 뒤 확정하고 설정 파일 잠금. 전용 SSD 반입(파기됨).
- 서류: 시험 신청서(항목별 4건), 보안서약서, 개인정보 동의서, 본시험 공문. `신청서/` 폴더.
